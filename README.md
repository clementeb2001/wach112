# WACH 112 – Lëtzebuerg

Browserspiel (Leitstellen-/Wachen-Simulation für Luxemburg). Eine einzige Datei (`index.html`), läuft auf iPhone, Android, Mac und PC ohne Installation und ohne Login.

- Spielstand: wird lokal im Browser gespeichert (pro Gerät getrennt).
- iPhone: Seite in Safari öffnen → Teilen → „Zum Home-Bildschirm“.
- 3D-Wachen: three.js (MIT-Lizenz, im Spiel eingebettet). Kartendaten: OpenStreetMap-Mitwirkende (ODbL).
